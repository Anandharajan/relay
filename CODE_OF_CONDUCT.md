# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, especially to first-time contributors and to people writing in their second or third language. Harassment, personal attacks and discriminatory language are not tolerated.

Report unacceptable behaviour privately to the maintainers through GitHub (Security → Report a vulnerability, or a direct message to a maintainer). All reports are reviewed and kept confidential.
